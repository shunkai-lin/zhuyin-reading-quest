# 單字拆音與合音

## 目前定案

使用者後續取消拆音檢核、保留既有整字朗讀過關；不使用中國大陸平台，也不申請外部評分帳號。以下評分研究僅保留為歷史背景，已不屬於實作需求。
現在採翰林公開示範影片的原站連結（不下載、不重新發布影音），逐步播放聲符、韻符與結合韻，再由瀏覽器合成完整字音。頁面附翰林來源連結。所有 50 個單字的拆音均有公開示範連結；片段播放失敗會提示重試，不用同音國字假冒音素示範。
播放器關閉、離開頁面或切題時停止示範；播放結束接下一個音，最後回整字合音。雙字詞與句子沿用原本直接朗讀。

2026-09-06 使用者要求：只有單字逐步拆音及檢核；雙字詞與句子直接讀。

教學順序：聲符（若有）→ 個別韻符 → 結合韻（若有）→ 含聲調的完整字音。
例如「天」：ㄊ → ㄧ → ㄢ → ㄧㄢ → ㄊㄧㄢ；「你」：ㄋ → ㄧ → ㄋㄧˇ。
「安」沒有聲符；「是」為單一聲符表示的完整音節，不另外捏造韻符。
個別音素不重複給星星；完整單字首次完成才沿用原本題目 ID 計分。

## 尚未解決的檢核能力

現有 Web Speech API 回傳辨識文字，不能當作聲符、韻符的聲學評分。
不得以同音國字、ASR 信心值或單純音量當作注音正確的證據。
拆音步驟目前只建立資料模型，尚未接入正式畫面或過關機制。

需選定並實測能處理台灣注音孤立聲符與結合韻的評分服務。
外部短錄音傳送與可能費用已詢問使用者；提供者、資料保留、價格與正確率均尚未定案。
若採大人逐音確認，畫面與紀錄必須明示為人工確認，不能標成自動檢核。
無法評分、權限被拒或沒有收音時，應允許重試，不判錯也不給過關。
驗證案例必須包含正確音、相近錯音、無聲、背景雜音與兒童實際錄音。

整字辨識維持既有方式；拆音僅用於示範。原評分服務規劃已取消。

## 免費優先的服務調查（2026-09-06）

使用者已接受尋找外部評分服務，以不用費用為優先。尚未建立服務帳號、購買方案或上傳兒童錄音。

- 訊飛流式語音評測：官方文件寫明建立應用預設每日 500 次，中文可回傳聲韻與聲調結果。`read_syllable` 指單字，不等於孤立聲符；中文拼音標註仍要求有效字典拼音，因此不能宣稱已支援全部注音拆音。API 需 AppID、APIKey、APISecret。
  https://www.xfyun.cn/doc/Ise/IseAPI.html
- 騰訊新版口語評測：`eval_mode=8` 明列拼音評測與音素準確度，但示例是完整音節 `shan3`；未確認孤立聲符與免費額度。舊版即將下線，不採用舊版文件作為串接依據。
  https://cloud.tencent.com.cn/document/product/1774/107402
- Azure Speech：F0 公開列出每月 5 小時語音轉文字，不能直接當作所有發音評分功能皆免費的證據；完整音節內的音素評分也不代表單独聲符可用。列為備選，需先核對所選評分功能與語系。
  https://azure.microsoft.com/en-us/pricing/details/speech/

免費優先可先用訊飛額度做能力驗證，但通過孤立聲符、結合韻及台灣兒童實測前，不選定為正式方案。免費額度不代表無限或永久免費；部署時必須限制呼叫量，不能自動轉付費。
訊飛 SDK 隱私政策涉及兒童同意與資料處理；尚未確認本案 Web API 的保留期限、訓練用途與資料區域，不能宣稱送出後立即刪除。
https://www.xfyun.cn/doc/total_sdk_privacy/ise_privacy.html

目前實測阻礙：沒有上述服務的 API 測試憑證，也沒有經同意用於驗證的真實拆音樣本。需在選定免費測試服務後取得帳號憑證；私密金鑰只能保存在伺服器環境，不能放進 GitHub Pages 前端。
